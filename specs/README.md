# Specs

Test plans (Markdown) written by the `playwright-test-planner` agent and read by
the `playwright-test-generator` agent.

| Seed file | Starting state | Use for |
|---|---|---|
| `tests/seed.spec.ts` | ParaBank home page, logged out | Login, Register |
| `tests/seed-logged-in.spec.ts` | Logged in, on Accounts Overview | Account Services pages |

Name plans `<module>.plan.md`, e.g. `bill-pay.plan.md`.
